# Source catalogue browsing

Updated 8 September 2026. Sources are grouped by topic, with alphabetical source
names within each group. Search accepts multiple terms across names,
organisations, topics, languages and declared coverage. Maritime search also
recognises ships, boats, shipping and AIS.

Combine Topic, Country or region, Language, Collection and Access filters. Clear
filters restores the whole catalogue. Country selections show explicitly
catalogued focus or registry jurisdiction. Worldwide sources are a separate
choice, not silently duplicated into every country. Coverage unspecified remains
available for sources without reviewed geography. Language never implies country.

Each source shows its organisation, geographic scope, format, collection mode
and key requirement. Coverage notes, identifiers and editorial rating context
expand separately. Ratings are not measured accuracy; a listed source is not proof
of current connectivity or use in a report. Scheduled/on-demand and key-required
labels describe configuration, not operational health. Administrators inspect
health through Admin Sources.

The authenticated local catalogue returned 126 sources, 11 topics and 10 country
options during verification: 70 worldwide, 36 regional and 20 unspecified entries.
Counts depend on deployment configuration. Secrets and operator endpoint URLs
are excluded from the public catalogue API.

Washington DC uses America/New_York, including daylight-saving changes. The five
world clocks sit 12 pixels lower than before, above map attribution.

Browser visual inspection was unavailable because the browser tool could not
verify the administrator-enforced access policy. Automated component interaction,
filter-combination and seasonal timezone checks cover the implemented behaviours.
