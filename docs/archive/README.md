# Documentation archive

These documents were moved here from `docs/` on 26 September 2026. They are
finished plans, implementation contracts, dated audits, reviews, acceptance records,
an agent handoff and the original proposal. Each one starts with a status line
naming the current document that describes the behaviour today.

Archived documents record what was planned, checked or known on their own dates.
Their test counts, branch names, open items and "current" statements are not
maintained. For current behaviour, start at the [documentation index](../README.md).
The [implementation plan](../MASTER_IMPLEMENTATION_PLAN.md) links to these records
where they explain past work, and the [development story](../DEVELOPMENT_STORY.md)
gives the chronology.
