# Regional research seed cases

Twelve synthetic development cases cover Russia, China and Iran, with four cases
per country: official claims, ambiguous organisation identity, language negation
and geographic uncertainty. They use fictional assertions and reserved URLs.
These are assistant-authored seed rubrics, not human-reviewed or held-out labels.

Run the existing evaluation command with this directory as the casebook. Model
execution requires an explicitly configured provider. Parsing the cases or replay
tests alone does not measure research quality. Review each reference rubric before
using it as a release gate; the 60-case benchmark remains separate unfinished work.
